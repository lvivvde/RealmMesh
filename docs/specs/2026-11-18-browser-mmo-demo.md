# 浏览器双人场景演示

状态：首版已实现。启动与双窗口试玩步骤见[本机双人网页演示](../operations/browser-demo.md)。

演示随 RealmMesh 仓库交付。开发者在本机启动含 Scene 的服务组与网页兼容进程；试玩者只需打开浏览器。沿用现有 HTTPS、Gateway 与 Realm 的 TLS/TCP 接入及 protobuf 线格式，不要求现有服务增加 WebSocket 监听。兼容进程属于前端工程，不是新的游戏服务。

## 试玩路径与验收

1. 两个浏览器窗口分别用不同的账号完成真实登录与排队。可使用预置演示账号，也可在本机启动器启用的注册页创建开发账号；只新增，不覆盖同名账号。注册后走原登录链。同一账号重复登录会顶替原 Realm Session。
2. 客户端经 Gateway 取得 Handoff 后连接指定 Realm。在选角阶段列出已有角色，也能创建并选中角色。
3. 两个角色进入同一场景分片。甲先进入，乙后进入，两端均能看见对方；甲乙分别移动，另一端均能看见服务端确认的位置变化。网页端不直连 Scene。
4. 用简单几何体表现地形和角色。首版不设 1.9 MB 硬上限，也不以公网部署作为验收条件。

## 网页与兼容进程

每个浏览器窗口通过 WebSocket 接入兼容进程，对应一份独立的客户端会话。网页提交登录、选角和移动等操作，显示排队进度、角色列表与场景状态。兼容进程复用 `game/client` 驱动 Login Chain，取得 Realm Session 后按现有协议处理角色与场景操作。WebSocket 接口只供网页与兼容进程使用，Gateway 和 Realm 不感知它。

进入场景后，兼容进程通过 `GetSceneState` 取得快照，再按快照水位衔接 `SceneEvent`。网页据此绘制本角色与其他成员；双方显示的位置以服务端确认为准。

## 镜头与移动操作

场景顶部显示角色名与已确认坐标。附近地图按同一份场景状态标出自己和附近角色；背包展示空槽位，不模拟掉落、交易或持久物品。

镜头固定为斜俯视，不提供旋转操作。摇杆方向以屏幕为准：向上拖动时，角色朝画面上方走，左右同理。

桌面左键点地走到目标格，右键点地以双倍步幅跑；两轴可同时移动，最后一步不越过目的地。按住拖动可改向，松开结束拖动，Esc 或窗口失焦取消目标。金色地面圆环标出目的地，不做障碍绕行。B / F9 打开背包，M 打开地图。触屏保留四向虚拟摇杆：拖回中心、松手或触控中断即停止发出移动指令。两种输入共用服务端确认落点。

登录语义见 [ADR-0008](../adr/0008-client-login-chain-shared-wire-and-redeemer-seam.md)；移动确认边界见 [ADR-0015](../adr/0015-scene-confirmed-location-and-binding.md)。
